# Improvement Deep-Dive — 0xhermexVM — 2026-10-21

Scope: main (pnpm monorepo: `apps/hermes-chat` Capacitor Android app, `apps/hermes-bridge`, `packages/*`). Sources read: root `package.json`, `.github/workflows/ci.yml`, `apps/hermes-chat/package.json`, `apps/hermes-chat/android/variables.gradle`, directory listings.

## Top recommendations (ranked, with effort S/M/L)

1. **Capacitor 7 → 8 + Android SDK 36 (M).** `@capacitor/* ^7.4.4`; latest is **8.5.3** (Oct 2026). Two drivers:
   - **CVE-2026-103922** (Oct 2026): WebView navigation guard validated host/scheme but not path — remote content loadable at app origin via the internal HTTP proxy path, exposing same-origin storage and plugin capabilities. Fixed in 7.6.9 / 8.3.5+; `^7.4.4` may already resolve to 7.6.9 via lockfile — **verify the lockfile and bump deliberately**, don't rely on semver drift for a security fix.
   - Android 16 (API 36): mandatory edge-to-edge, predictive back; `compileSdkVersion/targetSdkVersion = 35` → 36. Capacitor 8 requires Node 22+ (CI already on 22 ✓) and supports TS 7 configs. Re-test keyboard/safe-area behavior on API 31 + 36 after the bump (known upstream edge-to-edge regressions).
2. **pnpm 9 is EOL (S).** `packageManager: pnpm@9.0.0` — the 9.x line went EOL 2026-04-30. Current is **12.5.1** (Aug/Sep 2026, Rust install engine; lockfile format carried from v11). Jump 9 → 12: regenerate `pnpm-lock.yaml`, keep the `packageManager` pin, and adopt **pnpm catalogs** to kill the workspace drift below. Also bump CI `pnpm/action-setup` version accordingly.
3. **Workspace toolchain consolidation (S).** hermes-chat: vite ^6.3.5, vitest ^3.2.4, eslint ^9.39.1, TS pinned 5.9.2 — while the org's other repos run vite 8 / vitest 4 / newer TS, and root runs TS ^5.9.3. Use pnpm catalogs (or turbo + shared config) so `nostr-tools ^2.23.3` (→ 2.25.2), vite, vitest, TS are declared once. Drift here is how a bridge package and chat app end up disagreeing on event serialization.

## Missing gates (CI/tests/protection)

- CI (`ci.yml`) is the **best in the org**: frozen lockfile, `pnpm check`, smoke test, and nak pinned by SHA-256 — use this file as the template for the other repos.
- Gaps: no Android build job in CI (assembleDebug would catch Gradle/SDK drift; `release-android.yml` exists — confirm it runs on tags and that `HERMEXVM_SIGNING_PROPERTIES` never lands in logs). No gitleaks/secret scan. No lockfile-age or `pnpm audit` step. No branch protection on main.

## Quick wins (code/config)

- Add `pnpm audit --prod` (or osv-scanner) to CI; this app ships to Zapstore (`zapstore.yaml`) — supply-chain hygiene is the distribution channel's whole point.
- `turbo.json` + per-package scripts look healthy; add a `check-types` fan-out cache key so CI doesn't rebuild the world on docs changes.
- `.env.example` (2 KB) — good; add a comment per var noting which are secrets vs publishable (Nostr pubkey-style vars get confused with keys).
- Reproducible-build check for release APK (zipalign + `diffoscope` on two CI runs) strengthens the Zapstore story — Capacitor has regressed reproducibility before.

## Ecosystem alignment notes

- Capacitor 9.0.0-alpha exists (UIScene, edge-to-edge migrator); stay on 8.5.x stable until 9 final.
